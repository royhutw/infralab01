! =========================================================
! 生成樹與 L2 區域防禦 (STP, DHCP Snooping, DAI, CoPP)

! ============================
! DHCP Snooping Baseline
! ============================
! 啟用 DHCP Snooping（IPSG / DAI 的基礎）
ip dhcp snooping
! Option 82：若 DHCP Server 不支援或 IoT 裝置異常才關閉
! no ip dhcp snooping information option
! 加入所有 Access VLAN（避免漏掉 VLAN 導致 IPSG 阻擋合法主機）
ip dhcp snooping vlan 35,37,38,40,50,60,70-75,80,90,98
! Snooping DB：避免 Switch 重開後綁定表消失
! IOU 環境使用unix, 檔案命稱請依照實際需求修改
! Production 環境使用flash, 檔案命稱請依照實際需求修改
!ip dhcp snooping database unix:/core02_dhcp_snoop.db
ip dhcp snooping database flash:/core02_dhcp_snoop.db
! 建議 300 秒（5 分鐘）避免綁定表過期太久
ip dhcp snooping database write-delay 300
! 防止 MAC spoof / Rogue DHCP Client
ip dhcp snooping verify mac-address

! 啟用 DAI
ip arp inspection vlan 35,37,38,40,50,60,70-75,80,90,98
! 檢查:來源MAC是否與GigabitEthernet表頭一致(src-mac)、
! 目的MAC是否合理(dst-mac,主要對ARP Reply有效)、
! 以及IP是否合法(ip)
! 加了下面這行之後,建議先觀察一段時間 show ip arp inspection statistics
ip arp inspection validate src-mac dst-mac ip

! =========================================================
! CoPP (Control Plane Policing) - 保護 CPU
! =========================================================
! ============================
! ICMP
! ============================
ip access-list extended ICMP-COPP-ACL
 permit icmp any any

class-map match-all ICMP-CLASS
 match access-group name ICMP-COPP-ACL

! ============================
! ARP
! ============================
class-map match-any ARP-CLASS
 match protocol arp

! ============================
! DHCP
! ============================
ip access-list extended DHCP-COPP-ACL
 permit udp any eq 67 any
 permit udp any eq 68 any

class-map match-all DHCP-CLASS
 match access-group name DHCP-COPP-ACL

! ============================
! 802.1X / RADIUS
! ============================
ip access-list extended RADIUS-COPP-ACL
 permit udp any eq 1812 any
 permit udp any eq 1813 any

class-map match-all RADIUS-CLASS
 match access-group name RADIUS-COPP-ACL

! ============================
! SSH
! ============================
ip access-list extended SSH-COPP-ACL
 permit tcp any any eq 22

class-map match-all SSH-CLASS
 match access-group name SSH-COPP-ACL

! ============================
! Policy-map
! ============================
policy-map COPP-POLICY
 class ICMP-CLASS
  police 256000 conform-action transmit exceed-action drop

 class ARP-CLASS
  police rate 500 pps burst 1000 packets conform-action transmit exceed-action drop

 class DHCP-CLASS
  police 128000 conform-action transmit exceed-action drop

 class RADIUS-CLASS
  police 256000 conform-action transmit exceed-action drop

 class SSH-CLASS
  police 128000 conform-action transmit exceed-action drop

 class class-default
  ! 建議上線後先觀察 show policy-map control-plane 一段時間，
  ! 確認 class-default 沒有誤傷合法流量後，再將 exceed-action 改為 drop
  police rate 100 pps burst 200 packets conform-action transmit exceed-action transmit
  ! police rate 100 pps burst 200 packets conform-action transmit exceed-action drop

! ============================
! input service-policy
! ============================
control-plane
 service-policy input COPP-POLICY

 ! 改由NPS進行Fail政策管理:
 ! authentication event fail action authorize vlan 50
 ! =========================================================
 ! NPS 離線與失敗處置（關鍵修改）
 ! =========================================================
 ! 1. 當 RADIUS 伺服器 Dead (離線) 時：
 !    - Data Domain (後接 PC) 進入 Critical VLAN 98
 !    - Voice Domain (IP Phone) 自動放行並指派至 switchport voice vlan (VLAN 38)
 authentication event server dead action authorize vlan 98
 authentication event server dead action authorize voice
 ! 2. 當 RADIUS 伺服器 Alive 但無回應 / 未註冊 (No Response) 時：
 !    - Data Domain 進入 Guest VLAN 90
 !    - Voice Domain 自動放行至 Voice VLAN (VLAN 38)
 authentication event no-response action authorize vlan 90
 authentication event no-response action authorize voice

 ip dhcp snooping limit rate 15
